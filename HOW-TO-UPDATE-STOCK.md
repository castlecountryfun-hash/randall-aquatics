# How Brandon updates the board

1. Open `inventory-template.csv` in Google Sheets, Excel, or any spreadsheet.
2. Change qty, name, or price. Delete a line to remove a fish. Add a line for new stock.
3. Keep the four columns: qty, name, price, group.
4. Email the finished file (or paste the rows) to the update address with the subject line:

   **RANDALL STOCK**

5. The bot reads the file, updates the inventory, and the site refreshes.

Hot Deals on the home page stay separate. If a deal price changes, say so in the email.

Call or message before customers drive. The board is the source of truth after each update.
